# 데이터 카드

## 이 레포가 가진 데이터

| 자료 | 위치 | 출처·성격 | 라이선스 |
|---|---|---|---|
| 평가 케이스 6건 | `eval/cases/*.json` | 직접 작성한 조건(지역 이름·일수·이동수단·기대 반경·시간대). 장소·좌표·ID 없음 | 이 레포의 MIT |
| 테스트 픽스처 | `tests/` | 직접 작성한 합성 값(장소 이름·좌표·날짜·열쇠) | 이 레포의 MIT |

실제 장소 데이터·사용자 데이터·평가 결과·모델 출력은 담지 않는다. 기준선 평가 결과는 쓰는 사람이 자기 환경에서 만든다(`eval/README.md`).

## 실행 중에 지나가는 데이터

| 자료 | 어디서 오는가 | 어디로 가는가 | 기본 동작 |
|---|---|---|---|
| 장소 후보(이름·주소·좌표·분류) | hub `/v1/places`(hub 가 외부 장소 검색을 대신 부른다) | LLM 프롬프트(정리 후), 완료 페이로드 | 켜짐 |
| 날씨 | hub `/v1/weather` | LLM 프롬프트, 완료 페이로드의 안내 | 켜짐 |
| 블로그 후기 스니펫 | hub `/v1/reviews` | LLM 프롬프트 | **꺼짐**(`AGENT_REVIEWS_ENRICH_ENABLED`) |
| 후기 요약 입력 | BFF 요청 본문 | LLM 프롬프트 | **꺼짐**(`AGENT_SUMMARY_ENABLED`) |
| 학습 신호(노출 후보·선택·요청 조건) | 그래프 상태 | Streams `training` 필드 | **꺼짐**(`MAP_PROJECT_TRAINING_CAPTURE_ENABLED`) |
| 실행 기록 | 그래프 실행 | LangSmith | **꺼짐**(`AGENT_LANGSMITH_TRACING`) |

- LLM 프롬프트는 기본 합성 제공자로 가면 프로세스 밖으로 나가지 않는다. `AGENT_LLM_PROVIDER=gemini` 를 고르면 위 표의 "LLM 프롬프트" 자료가 Gemini API 로 전송된다. 외부 장소·후기 본문을 모델로 보내도 되는지는 각 제공자의 이용약관과 사용자 동의 조건을 쓰는 사람이 확인해야 한다.
- 좌표는 서비스 사이에서 늘 봉투로 오가고, 체크포인터를 켜면 저장 전에 봉한다([architecture.md](architecture.md) 보안 구성).

## 받는 법과 재생성

- 장소·날씨·후기 자료는 hub 가 외부 API 에서 받는다. 받는 법과 각 제공자의 이용조건은 map-project-hub 의 `docs/data.md` 를 따른다. 이 레포는 그 자료를 저장하지 않는다.
- 성향 통계 파일(`AGENT_SEGMENT_STATS_PATH`)은 직접 모은 세션 기록으로 `python -m eval.segment_stats` 가 만든다. 묶음(연령대·성별)×장소 칸마다 노출이 `DEFAULT_MIN_SUPPORT`(3)회 미만이면 그 칸을 쓰지 않는다. 경로를 비우면 랭킹은 이 파일을 쓰지 않는다(기본).
  - 주의: 문턱은 노출 횟수 기준이라 한 사람의 여러 세션만으로도 넘을 수 있다. 실제 사용자 기록으로 만든 통계 파일은 사람 수 기준의 익명성을 따로 확인하기 전에는 공유하지 않는다.

## 한계

- 평가 케이스는 조건만 적은 것이라, 같은 케이스라도 외부 응답(장소 검색·날씨)이 달라지면 점수가 흔들린다(`eval/README.md` "아직 없는 것").
- 합성 제공자의 결과는 후보 순위를 그대로 따른 틀 문장이라 추천 품질을 대표하지 않는다.
- 비공개 운영본의 체크포인트·스트림 기록·통계 파일과는 호환을 보장하지 않는다(이름·형식 판이 다르다).
