# 0004. 방문 순서와 구간은 모델이 아니라 계산으로 정한다

## 맥락

동선을 모델에 맡기면 호출 1회가 더 들고, 좌표가 있는데도 순서·거리가 엇갈렸다. 사용자가 장소를 직접 고른 요청까지 모델을 거칠 이유가 없었다.

## 선택지

1. 모델이 순서와 구간을 정한다
2. 좌표로 계산하고, 사용자가 고른 경로(`stage=route`)는 모델을 아예 부르지 않는다

## 결정

두 번째. `recommend_route` 가 좌표로 순서·구간을 계산하고, 시간축(`build_timeline`·`fit_time_budget`)도 결정적으로 돈다. `stage=route` 는 입력 순서를 지키고 `optimize=true` 일 때만 최적화하며, LLM 호출은 0회다.

## 결과

초기 추천의 LLM 호출이 선정 1 + 이유 1 로 줄었다. 거리·시간은 직선 추정이며, 도로 기준 값은 하류가 덮어쓴다.
