# 0009. 평가는 LLM 이 아니라 결정적 채점기로 한다

## 맥락

모델을 바꾸거나 랭킹을 고친 뒤 나아졌는지를 같은 자로 재야 한다. 채점을 외부 모델에 맡기면 재는 자와 재는 대상이 같은 것에 묶인다.

## 선택지

1. LLM 채점
2. 망 호출 없는 결정적 채점(형태·실측·반경·순서·시각 다섯 축)

## 결정

두 번째. `eval/` 의 채점기는 저장한 결과만 읽고 같은 입력이면 같은 점수를 낸다. 기준선과 비교해 회귀하면 0 이 아닌 값으로 끝난다.

## 결과

한국어 이유의 품질은 재지 않는다. 기준선 파일은 쓰는 사람이 자기 결과로 만든다.
