# 0011. 기본 LLM 제공자를 결정적 합성 제공자로 둔다

## 맥락

공개본은 내려받은 사람이 키나 비용 없이 끝까지 돌려 볼 수 있어야 하고, 기본 동작이 누군가의 유료 계정을 부르면 안 된다.

## 선택지

1. Gemini 키를 필수로 요구
2. 합성 제공자를 기본으로, Gemini 는 고를 때만

## 결정

두 번째. `AGENT_LLM_PROVIDER=fake` 가 기본이다. 합성 제공자는 프롬프트의 데이터 태그만 읽어 후보 앞에서부터 고르고, 이유·옷차림·요약을 틀 문장으로 채우며, 문장마다 `[합성]` 을 붙인다. `gemini` 를 고를 때만 키를 검사하고 호출 한도기를 띄운다.

## 결과

빠른 시작이 외부 호출 없이 추천까지 끝난다. 합성 결과는 품질을 대표하지 않으며, 기록(`model`)에도 `fake` 로 남는다.
